# jiaruichen224.github.io

陈佳锐的学术个人主页，包含个人介绍、教育经历、获奖荣誉、学术论文和发明专利。

## 发布到 GitHub Pages

1. 在 GitHub 创建公开仓库 `jiaruichen224.github.io`。
2. 将本目录中的全部文件上传到仓库根目录。
3. 进入仓库的 `Settings` → `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 选择 `main` 分支和 `/ (root)` 目录，点击 `Save`。
6. 等待数分钟后访问 `https://jiaruichen224.github.io`。
